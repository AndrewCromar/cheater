# Cheats for "Unnamed Pogo Game" on steam.

## Using the Installer

- Open the start menu, search for "PowerShell", and open it.
- Run this command:

```powershell
irm https://raw.githubusercontent.com/AndrewCromar/cheater/main/patch.ps1 | iex
```

- Wait for it to finish then run the game.
- Done.

## Uninstalling

- Open steam.
- Right click the game.
- Go to Properties > Installed Files.
- Press the "Verify integrity of game files" button.
- Done.
